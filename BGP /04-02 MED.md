# 4-1 인바운드 경로 제어 (MED)
BGP에서 `MED(Multi-Exit Discriminator)`는 AS 사이에서 상대 AS가 특정 네트워크에 도달하기 위해서 해당 AS에 들어오기 위한 경로가 여러 개 일 때 특정 경로로 트래픽을 유도할 때 사용하는 속성이다.
MED는 더 작은 속성 값을 가진 경로가 우선적으로 선택된다. `MED`는 iBGP 내부에 그대 전달되지만, EBGP 환경에서는 인접 AS에게만 이 값을 광고한다. 광고를 받은 라우터는 다른 AS에 광고를 할 때 MED 값 자체를 없애고 전달한다. 그 이유는 MED 값이 IGP 메트릭보다 높은 우선순위를 가지게 되어 내부 AS 라우터가 외부로 나가는 경로르 선택할 때 혼동을 줄 수 있기 때문이다.
