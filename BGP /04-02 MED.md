# 4-1 인바운드 경로 제어 (AS-Path Prepend)

## 개요

BGP는 같은 목적지에 대해 여러 경로를 광고받으면, 정해진 순서의 속성 비교를 통해 **best path** 하나를 선정한다.

이웃에게 아무 정책 없이 광고를 보내면 상대는 기본 규칙으로 경로를 고르므로, 나에게 들어오는 트래픽이 **의도한 경로로 오지 않을 수 있다.**

이를 해결하기 위해 이웃에게 광고를 보낼 때(**out**) route-map으로 **AS-Path Prepend**를 설정하여, 상대가 **내가 원하는 경로를 선택하도록 유도**한다. 이때 **AS-Path Prepend**를 설정하여 광고하는 네트워크의 AS-Path를 길게 설정하여 상대 AS에서 들어오는 트래픽을 원하는 경로로 들어오게 할 수 있다.


## 동작 방식

1. 내가 이웃에게 광고를 보낼 때(**out**) route-map으로 AS-Path Prepend를 설정한다.
2. 상대는 여러 경로 중 AS-Path가 더 짧은 경로를 **best path**로 선택한다.
3. 그 결과 나에게 들어오는 트래픽이 **내가 원하는 경로**로 유도된다.

## 1. 테스트 구성도

- `AS65001` R1, R2 : AS65001에 속한 라우터로 R3과 ISP가 통신하기 위한 중간 경로이다 **R3**의 20.20.20.1/32을 광고한다.
- R3 : ISP와 통신하기 위한 라우터로 20.20.20.1/32의 호스트 IP를 가지며 R1, R2 방향으로 static 라우팅을 잡고 있다. (우선순위는 R1 방향)
- `AS65002` ISP : R3과 통신하기 위한 라우터로 `AS65002`이며 **R1**과 **R2**와 `eBGP` 피어링을 맺고 있다.

<br>

## 2. 테스트 시나리오

1. MED로 AS 65001의 주 회선(Link-A)을 정하고, ROUTER_1이 Link-A를 best path로 선택하는지 확인한다.
2. AS가 광고하는 네트워크 2개(20.1.0.0/30, 30.1.0.0/30)가 서로 다른 회선을 best path로 잡도록 prefix별 MED를 설정한다.

<br>

## 3. 테스트

### R1 Config (AS65001)
```java
ip route 20.20.20.1/32 10.0.100.2

route-map MAP_MED_100 permit 10
  set metric 100 
vrf context management

interface Ethernet1/1
  no switchport
  ip address 10.0.100.1/30
  no shutdown

interface Ethernet1/2
  no switchport
  ip address 10.0.10.1/30
  no shutdown

router bgp 65001
  router-id 10.255.0.1
  address-family ipv4 unicast
    network 20.20.20.1/32
  neighbor 10.0.10.2
    remote-as 65002
    address-family ipv4 unicast
      route-map MAP_MED_100 out
```

---

### R2 Config (AS65001)
```java
ip route 20.20.20.1/32 10.0.200.2

route-map MAP_MED_200 permit 10
  set metric 200 
vrf context management


interface Ethernet1/1
  no switchport
  ip address 10.0.200.1/30
  no shutdown

interface Ethernet1/2
  no switchport
  ip address 10.0.20.1/30
  no shutdown

router bgp 65001
  router-id 10.255.0.2
  address-family ipv4 unicast
    network 20.20.20.1/32
  neighbor 10.0.20.2
    remote-as 65002
    address-family ipv4 unicast
      route-map MAP_MED_200 out
```

---

### R3 Config 
```java
interface Ethernet1
   no switchport
   ip address 10.0.100.2/30
!
interface Ethernet2
   no switchport
   ip address 10.0.200.2/30

interface Loopback0
   ip address 20.20.20.1/32

ip route 0.0.0.0/0 10.0.100.1
ip route 0.0.0.0/0 10.0.200.1 10
```

---

### ISP Config (AS65002)
```java
interface Ethernet1
   no switchport
   ip address 10.0.100.2/30
!
interface Ethernet2
   no switchport
   ip address 10.0.200.2/30

interface Loopback0
   ip address 20.20.20.1/32

ip route 0.0.0.0/0 10.0.100.1
ip route 0.0.0.0/0 10.0.200.1 10
```
