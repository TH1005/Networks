## BGP

### BGP란?
BGP(Border Gateway Protocol)은 서로 다른 AS(Autonomous System)에 속한 라우터 간에 라우팅 정보를 교환하는 외부 게이트웨이 프로토콜이다. 여기서 AS는 전 세계적으로 거대한 인터넷을 구성하는 하나의 독립된 네트워크 단위를 말한다.
BGP를 사용하는 이유는 수십만 개에 달하는 전 세계 인터넷 경로를 OSPF 같은 내부 라우팅 프로토콜(IGP)로 처리하기에는 확장성 한계가 있을 뿐만 아니라, 통신사 및 기업 간의 비용·보안 정책에 따라 경로를 유연하게 제어(Policy-Based Routing)해야 하기 때문이다.

BGP는 TCP 179번을 통해서 Peer 간 세션을 맺고 주기적으로 keepalive 상태를 확인하고, 세션이 끊길 시 다른 Peer들 에게도 Update 패킷을 전송하여 경로를 업데이트 하도록 작동한다.

BGP는 거리벡터(Distance Vector) 알고리즘을 뼈대로 하는 경로벡터(Path Vector) 알고리즘을 사용하는 하는 프로토콜이다.
BGP가 경로벡터를 사용하는 이유는 '라우팅 루프'를 해결 하기 위함이다. A, B, C 라우터가 있고 A가 X라는 네트워크를 광고한다면,
- A는 B에게 X네트워크로 가려면 A를 거쳐가라고 광고.
- B는 C에게 X네트워크로 가려면 B를 거쳐가라고 광고.
- C는 다시 A에게 X네트워크로 가려면 C를 거쳐가라고 광고.

이렇게 광고가 되고 A와 X네트워크를 가진 라우터 간 회선 장애나 메트릭이 꼬이면 루프가 C > B > A > C > B > A 순으로 TTL이 0이 될 때 까지 무한 루프가 돌 수 있다. 이를 방지하기 위해서 광고 패킷을 받았을 때 AS Path에 내 AS 번호가 있다면 그대로 드랍시키는 경로벡터 알고리즘을 사용하는 것이다.
